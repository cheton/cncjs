# W3 final dependency and UI reconciliation

W3 starts from R6 commit `c1671769`. Dependency/import audit: [dependency-audit.json](artifacts/w3/dependency-audit.json). Remove only four proven consumer-free direct packages and the remaining loading CSS; Yarn prunes their orphaned graph. Bootstrap Buttons, rc-trigger direct dependency, react-select/infinite-tree/repeatable/foreach, styled-components and XState were already removed. `rc-trigger` remains transitively required by rc-tooltip/rc-slider and is not forced to zero. Their exact reasons/tests and eighteen non-React domain classes are in [ui-migration-allowlist.json](../../../../scripts/ui-migration-allowlist.json). [P6 reconciliation](p6-reconciliation.md) maps every original non-widget path; the W3 AST/import gate validates current aliases, relative/barrel imports and inheritance. No legacy component instance API or bootstrap UI import remains. `src/package.json` needs no frontend additions.

User steering: Tonic DatePicker is available; there is no current date-picker view to migrate. All loading indicators use Tonic Spinner, including the pre-bundle bootstrap HTML generated with React server rendering. Existing server-language placeholders remain intact and tested with Hogan. Determinate percentages/controller values retain progress bars. Removed unused loading.gif and loader.styl. Loading state, controller commands and transport owners are unchanged.

Production vendor discovery previously scanned test sources and included testing-library plus application test helpers. A real-config regression failed first; exclude `__tests__` and `src/app/test` from vendor discovery, then verify it retains React and excludes test imports. This addresses packaged startup dependencies, not only compilation.

A separate read-only UI validation workflow runs guard fixtures, frontend/lint/Node gates, production build and packaged entrypoint checks on the migration branch. It uploads a seven-day build artifact and does not publish a release. Production runs only in CI, per standing instructions.

R6 functional/browser/simulator/performance evidence remains applicable to unchanged controller/session/resource logic. W3 Spinner changes have frontend/SSR regression evidence; no new W3 browser screenshot is claimed. Final status depends on CI production results.
